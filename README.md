# 家庭用电智能诊断器（手机版 H5 原型）

基于《家庭用电智能诊断器--电量测算模型》及《家庭用电测算优化建议.md》实施的
**家用电器负荷计算**移动网页原型（数据驱动、按计算模型分派）。

## 运行方式
1. 直接用手机或浏览器打开 `index.html`；
2. 或本地起服务（推荐）：
   ```bash
   python -m http.server 8080
   ```
   然后访问 `http://<本机IP>:8080/`（手机与电脑同一局域网即可打开）。

## 计算模型（v2：不再所有电器共用一套公式）
| 模型 | 设备 | 公式要点 |
|------|------|----------|
| `constant_power` | 风扇/电视/照明 | 功率×小时×天数，高温只延长时长不放大功率 |
| `thermal_ac` | 空调 | 设定温度与室外温度合并为 ΔT 单变量；变频负荷随 ΔT 分段(0.5~0.88)；不再能效双计 |
| `nameplate_daily` | 冰箱 | 主输入=能效标识日耗电(kWh/24h)，不问压缩机功率与运行小时 |
| `cycle` | 洗衣机 | 月次数 × 单次程序电耗 + 烘干附加，滚筒耗电大头在加热水 |
| `hot_water` | 储水电热水器 | 物理公式：水量×温差/效率 + 保温暖损失(随设定温度) |
| `always_on` | 常开设备 | 功率×24h |

月电费 = 全屋合计 kWh × 电价(默认 0.6 元/kWh)。阶梯/峰谷分时计费后续版本处理。

## 诊断体系
- **单台诊断**：计算页「查看本机诊断」，规则式建议 + 差值量化；
- **全屋诊断**（诊断 Tab）：用电排名、占比、省电潜力汇总；
- **潜力计算冻结气候因子**（室外温度/湿度/围护），只优化行为与设备项，
  不再把「室外35℃」假设成最省档。

## 文件结构
- `index.html` 应用外壳 + 底部导航（设备/我的设备/诊断）
- `css/style.css` 移动端设计系统
- `js/data.js` 设备定义（model 声明 + 字段分组 + 因子 role）
- `js/engine.js` 多模型计算引擎 + 规则式诊断
- `js/app.js` 渲染 / 导航 / 实时计算 / 单台+全屋诊断 / 记录

新增设备只需在 `js/data.js` 声明 `model` 与 `fields`，引擎与页面无需改动。
字段结构变更时递增 `app.js` 中 `SCHEMA_VERSION`，旧 localStorage 自动重置。
