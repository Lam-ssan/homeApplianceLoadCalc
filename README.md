一个纯前端 H5 应用，用于测算家用电器的月用电量与电费，并给出节能诊断建议。无需后端、无需安装依赖，浏览器打开即用。

## ✨ 功能特性

- **设备选择**：内置 15 类常见家用电器（风扇、空调、冰箱、洗衣机、热水器、电视、电脑、电饭煲、微波炉、抽油烟机、吹风机、吸尘器、照明、常开设备、即热热水器）
- **参数化计算**：每类设备提供预设功率、使用习惯、环境条件等参数输入
- **实时结算**：即时显示单台设备的月用电量（kWh）与预估电费
- **节能诊断**：基于规则引擎生成诊断建议，环形图展示省电潜力
- **全屋汇总**：汇总所有已添加设备的台数、总用电量、总电费与省电潜力

## 🧮 计算模型

不同电器按物理特性采用不同计算模型（见 `js/engine.js`）：

| 模型 | 适用设备 | 计算方式 |
|------|----------|----------|
| `constant_power` 恒功率 | 电视、电脑、电饭煲、微波炉等 | 功率 × 时长 + 待机/保温项 |
| `gear_weighted` 多档位加权 | 电风扇 | Σ(档位功率比 × 各档时长) + 待机项 |
| `thermal_ac` 热力空调 | 空调 | ΔT 单变量 + 变频分段负荷 + 围护/湿度/老化 |
| `nameplate_daily` 铭牌日耗电 | 冰箱 | 能效标识 kWh/24h × 天数 |
| `cycle` 循环批次 | 洗衣机 | 使用次数 × 单次电耗 + 烘干 |
| `hot_water` 热水物理公式 | 储水电热水器 | 水量 × 温差 / 效率 + 保温暖损失 |
| `always_on` 常开设备 | 路由器等 | 功率 × 24h × 天数 |

省电潜力计算会**冻结气候类因子**（如室外温度、湿度），仅优化用户可改变的行为与设备项。

## 📂 项目结构

```
homeApplianceLoadCalc/
├── index.html              # 入口页面（多视图切换）
├── css/style.css           # 样式
├── js/
│   ├── data.js             # 数据层：设备定义 + 参数字段 + 系数查表
│   ├── engine.js           # 计算引擎：分派模型计算、省电潜力、诊断建议
│   └── app.js              # 视图渲染与交互逻辑
├── 家庭用电测算优化建议.md   # 后续迭代实施规格书（电价体系、模型细化等）
└── *.xlsx                  # 原始电量测算模型与调研数据
```

## 🚀 快速开始

无构建步骤、零依赖，任选一种方式运行：

```bash
# 方式一：直接用浏览器打开
start index.html

# 方式二：本地静态服务（推荐）
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080` 即可。页面已适配移动端，可直接部署到任意静态托管平台（Gitee Pages、GitHub Pages 等）。

## 🔮 已知局限与后续计划

当前版本仍为原型阶段，主要待改进点（详见《家庭用电测算优化建议.md》）：

- 电价目前写死为 0.6 元/kWh，尚未支持广东阶梯电价与峰谷分时电价
- 缺少家庭画像（人口数、地域等共享参数）
- 各设备参数体系需按规格书逐步细化
