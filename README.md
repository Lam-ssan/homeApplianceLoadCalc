# 家庭用电智能诊断器（手机版 H5 原型）

基于参考 Excel《家庭用电智能诊断器--电量测算模型》的系数乘算法，构建的**家用电器负荷计算**移动网页原型。
以**电风扇**为完整范例，并扩展为**多设备通用框架**（空调/冰箱/洗衣机/电视）。

## 运行方式
1. 直接用手机或浏览器打开 `index.html`；
2. 或本地起服务（推荐，避免个别浏览器本地文件限制）：
   ```bash
   python -m http.server 8080
   ```
   然后访问 `http://<本机IP>:8080/`（手机与电脑同一局域网即可在手机打开）。

## 计算模型（数据驱动）
```
月用电量(kWh) = 功率(W)/1000 × 每天小时 × 每月天数 × 数量 × Π(各因子系数)
月电费(元)   = 月用电量 × 电价(默认 0.6 元/kWh)
```
新增设备只需在 `js/data.js` 增加一段 `params + factors` 配置，引擎与页面无需改动。

## 电风扇示例（与 Excel 同结构）
落地扇 60W，高速(1.0)，8h/天，30天，1台，老化1.0，温度 32-35℃(1.2)，独立(1.0)：
`60/1000 × 8 × 30 × 1 × 1 × 1 × 1 × 1.2 × 1 = 17.28 kWh`，电费 ≈ 10.37 元。

## 文件结构
- `index.html` 应用外壳 + 底部导航（设备/诊断/我的）
- `css/style.css` 移动端设计系统
- `js/data.js` 设备定义 + 系数查表（风扇完整，其余扩展）
- `js/engine.js` 通用计算引擎 + 电费 + 诊断建议
- `js/app.js` 渲染 / 导航 / 实时计算 / 记录
